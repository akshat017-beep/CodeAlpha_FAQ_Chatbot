🤖 FAQ Chatbot using NLP

An intelligent FAQ Chatbot built using Python, Flask, NLTK, and Scikit-learn.

This chatbot uses Natural Language Processing (NLP) techniques to understand user questions and provide the most relevant FAQ answer using cosine similarity.

---

🚀 Features

- NLP Text Preprocessing
- Tokenization using NLTK
- Stopword Removal
- TF-IDF Vectorization
- Cosine Similarity Matching
- Interactive Chatbot UI
- Responsive Design
- Flask Backend
- Real-time Chat Response

🧠 How It Works

1. User enters a question.
2. Text is preprocessed using NLP.
3. TF-IDF vectorization converts text into vectors.
4. Cosine similarity finds the closest FAQ match.
5. Best matching answer is returned.
